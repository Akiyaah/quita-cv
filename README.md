## Features

- Split hero section with a profile photo and career objective
- Fixed navigation bar with smooth scrolling and active-section highlighting
- Mobile hamburger menu
- Loading screen
- Scroll reveal animations
- Animated technical skill bars
- Card layouts with hover effects for education, projects, experience, and certifications
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries, keyframe animations)
- JavaScript (DOM manipulation, Intersection Observer)
- Google Fonts (DM Sans)
- Git and GitHub
- Vercel (deployment)

## Design

- **Colors:** pastel orange and charcoal, with cream for light sections
- **Font:** DM Sans
- **Layout:** split hero with card-based sections on alternating dark and cream backgrounds
